# 📂 Projects Included

## 🚢 1. Titanic Survival Prediction

### 📌 Objective

Build a classification model to predict whether a passenger survived the Titanic disaster.

### 🔍 Project Highlights

- Data Cleaning
- Handling Missing Values
- Feature Encoding
- Exploratory Data Analysis (EDA)
- Model Comparison
- Feature Importance Analysis

### 🤖 Models Used

- Logistic Regression
- Decision Tree
- Random Forest

**🏆 Best Model:** Random Forest

---

## 📈 2. Sales Prediction Using Machine Learning

### 📌 Objective

Predict product sales based on TV, Radio, and Newspaper advertising expenditure.

### 🔍 Project Highlights

- Data Visualization
- Correlation Analysis
- Regression Model Comparison
- Feature Importance
- Actual vs Predicted Sales Analysis

### 🤖 Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

**🏆 Best Model:** Random Forest Regressor

---

## 💳 3. Credit Card Fraud Detection

### 📌 Objective

Develop a machine learning model to detect fraudulent credit card transactions.

### 🔍 Project Highlights

- Data Cleaning
- Feature Scaling
- Handling Class Imbalance
- Exploratory Data Analysis
- Model Comparison
- Fraud Detection

### 🤖 Models Used

- Logistic Regression
- Random Forest

**🏆 Best Model:** Random Forest
