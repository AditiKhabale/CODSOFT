## 📌 Project Overview

This project was completed as part of my **Data Science Internship at CodSoft**.

The main objective of this project is to predict product sales based on advertising budgets spent on TV, Radio, and Newspaper advertisements. I explored the dataset, analyzed the relationship between advertising and sales, trained different regression models, and compared their performance to identify the most accurate model.

This project gave me practical experience in regression analysis, data visualization, and machine learning model evaluation.

---

## 🎯 Objective

- Predict product sales using advertising data.
- Explore and understand the dataset through visualizations.
- Train multiple regression models.
- Compare model performance using evaluation metrics.
- Identify the best-performing model for sales prediction.

---

## 📂 Dataset

The dataset contains advertising budgets and corresponding product sales.

### Features

- TV Advertising Budget
- Radio Advertising Budget
- Newspaper Advertising Budget

### Target Variable

- Sales

---

## 🛠️ Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## ⚙️ Project Workflow

- Imported the required libraries.
- Loaded and explored the dataset.
- Checked for missing values and cleaned the data.
- Performed Exploratory Data Analysis (EDA).
- Visualized relationships between features and sales.
- Split the dataset into training and testing sets.
- Trained different regression models.
- Compared model performance.
- Selected the best-performing model.

---

## 🤖 Machine Learning Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

---

## 📊 Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

🏆 **Best Performing Model:** Random Forest Regressor
